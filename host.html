How to use

  1. Fill in the details and your guest list here.
  2. Click Download guest page and upload that file to any web host (for example Netlify Drop) to get a link. Send the link to guests.
  3. Guests reply to your WhatsApp. Log each reply above; the total updates. Download sheet gives you the list for Excel.
  4. If you add guests later, download the guest page again and replace the uploaded file.
