How to use

  1. Add each invitation here with the mobile number you'll send it to and the seats offered.
  2. Send guests the invitation link. They enter their number and reply; you see it here straight away.
  3. Each number can reply once. To change a reply, set it here yourself, or set it back to Awaiting reply to let the guest answer again.
  4. Download sheet gives you the list for Excel.
